One dad joke, written to be told out loud at the barbecue:

> Why did I bring a ladder to the barbecue? I heard the steaks were high.

`main.py` (Python 3.13 standard library only, deterministic, no network)
writes that single joke — 70 characters — to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

Local run (writes to `./out/entry.txt` instead of `/output/entry.txt`):

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
